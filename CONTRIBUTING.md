# Panduan Kontribusi
## Penamaan Branch
feat/, fix/, docs/, chore/, hotfix/
## Pesan Commit
Ikuti Conventional Commits, contoh: feat: tambahkan skrip pemeriksaan
## Alur
1. Buat branch dari main
2. Commit kecil dan atomik
3. Push, buka pull request, isi template
4. Minta tinjauan, perbaiki, lalu gabungkan setelah disetujui
